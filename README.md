A premium scroll-driven hero section recreated using React, Tailwind CSS and GSAP ScrollTrigger.

## Technologies

- Tailwind CSS
- GSAP
- GSAP ScrollTrigger

## Features

- Full-screen hero section
- Letter-spaced headline
- Staggered headline animation
- Animated statistics
- Scroll-driven car animation
- Scroll-linked rotation
- Scale and translation
- GSAP ScrollTrigger
- Responsive design
- Reduced-motion support

## Animation

The hero animation is connected to scroll progress using GSAP ScrollTrigger.

The main visual uses transform-based animation:

- translate
- scale
- rotate
- opacity
